# 판도 · 서기 475년

고구려·백제·신라 중 한 나라의 조정을 맡아 475년 겨울부터 150일을 플레이하는 한반도 역사 시뮬레이터입니다.

## 실행

저장소를 내려받아 `index.html`을 브라우저로 엽니다. 지도와 게임 데이터가 포함되어 있어 별도 빌드 없이 실행됩니다. 로컬 서버는 저장소 루트에서 `python -m http.server 8000`으로 시작할 수 있습니다.

## 플레이

지도나 목록에서 나라를 선택하고 시작합니다. 기본은 2배속이며 1배속, 4배속, 일시정지를 지원합니다. 이전 경계는 점선으로 남고 현재 전선과 접경 거점의 소속이 바뀝니다. 세 번의 가상 사건에서 시간이 자동으로 멈춥니다.

제안된 선택지를 누르거나 **직접 결정 쓰기**로 명령을 내립니다. 자유 입력은 로컬 정책 규칙으로 최대 두 가지 방향을 판독합니다. 판독 결과를 보고 방향을 직접 지정할 수 있습니다. 결정은 곡물·민심·교역, 이후 전선과 연대기에 반영됩니다. 같은 탭에서 새로고침하면 진행 상황을 복원합니다.

## 지도와 역사 자료

- 실제 해안선과 하천은 [Natural Earth 1:10m](https://www.naturalearthdata.com/)을 사용했습니다. 산줄기와 해저 지형의 음영은 [Mapzen Terrain Tiles](https://registry.opendata.aws/terrain-tiles/)의 표고 자료에서 생성했습니다. 현대의 지리 지형을 Web Mercator 좌표에 표시합니다.
- 475년 한성 함락과 웅진 천도는 [국사편찬위원회 우리역사넷](https://contents.history.go.kr/front/hm/view.do?levelId=hm_009_0050), 시대별 장비는 국립중앙박물관 등 전시 자료를 참고했습니다. 게임의 **지도와 사료**에 자료별 링크가 있습니다.
- 시작 세력권은 5세기 후반 판세를 근사한 시나리오입니다. 가야는 여러 가야 세력을 합쳐 표시합니다. 재생 후의 전선, 세력별 수치, 사건과 결말은 가상 역사입니다.

`tools/build_atlas.py`는 동봉된 지도 이미지를 원자료에서 다시 만드는 선택적 도구입니다.
